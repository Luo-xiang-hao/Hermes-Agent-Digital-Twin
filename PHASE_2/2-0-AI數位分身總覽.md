# 📅 2026-10-01｜🚀 第二階段 2-0｜我的 AI 數位分身：總覽

## 🎯 我想做什麼

第一階段，我把 Hermes Agent 的基礎建設跑起來了 🛠️。第二階段，我想做一件更個人的事：**做出一個像我自己的數位分身**。

不是一個通用的 Agent，而是一個會用我的思考邏輯說話、照我的判斷行事、記得我是誰的 Agent 🤖。我想把講義說的「蒸餾人實作」真正做一遍——把我的思維、價值觀、人格、知識，變成可執行的 `.md` 檔案。

說得直白一點：**我想蒸餾我自己。** 🧪

---

## 🛠️ 我接下來要做的四件事

### Step 1 · 確認環境 🖥️
先確認 Hermes Agent 已安裝，`~/.hermes/` 目錄結構完整，並看一下預設的 `SOUL.md` 長什麼樣。

### Step 2 · 寫 `SOUL.md`（蒸餾我的人格） 🫀
`SOUL.md` 是 agent 的「靈魂」——它定義這個分身是誰、怎麼說話、避免什麼。要讓它像我，這是我要寫的第一個檔案。講義用四個維度引導我反思：
* 🪞 **Identity**——我是誰
* 🗣️ **Style**——我怎麼說話
* 🚫 **Avoid**——我不容忍什麼
* 🧭 **Defaults**——我遇到模糊狀況時怎麼辦

### Step 3 · 寫 `USER.md` + `AGENTS.md`（蒸餾我的工作脈絡） 🧠
`SOUL.md` 回答「我是誰」，但分身還需要知道我平常在做什麼、我的工作偏好是什麼。
* 📌 **`USER.md`**：我的偏好與背景。路徑 `~/.hermes/memories/USER.md`。
* 📌 **`AGENTS.md`**：專案層的工作說明書。放在專案資料夾下，當我在該資料夾啟動 Hermes 時自動載入。

### Step 4 · 封裝 `.skill`（蒸餾我的工作流程） ⚙️
把我反覆做的一件事，封裝成可重用的技能。之後 Hermes 可以自動或手動呼叫它。

---

## 📱 這些檔案會怎麼生效

* 🫀 **`SOUL.md`**：全域。跟著我的分身走。
* 🧠 **`USER.md`**：全域。跟著我的分身走。
* 📌 **`AGENTS.md`**：專案。只在那個專案資料夾啟動 Hermes 時載入，切換專案會自動更換。
* ⚙️ **`.skill`**：可呼叫。非自動載入，需手動或由 Agent 觸發。
