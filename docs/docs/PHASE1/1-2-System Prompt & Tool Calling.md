# 📅 2026-09-21｜Phase 1-2 System Prompt 優化與 Tool Calling 實作

## 🎯 今日目標
延續 Phase 1-1 的基礎建置，本階段目標為將 Agent 從「單向資訊提供者」轉型為「具備引導與即時查詢能力的專業顧問」。具體實作項目包含：
1. 透過 System Prompt 設計，讓 AI 產生更擬人化、個人化的回覆。
2. 導入 Tool Calling（Web Search）機制，使 Agent 能夠查詢即時與在地化資訊。

## 🛠️ 實作過程

### 第一部分：System Prompt 設計與前後對比測試

#### 1.1 設計理念
一開始測試時，我發現未經設定的 AI 雖然懂很多鸚鵡知識，但回覆就像「維基百科」一樣，只會直接給出標準答案。舉例來說，我問「推薦什麼鸚鵡？」，它就直接丟出「玄鳳鸚鵡」，完全沒考慮到我住哪裡、有沒有時間陪牠、預算多少。
這樣其實很危險。

如果 AI 推薦叫聲很大的鸚鵡給住小套房的人，鄰居一定會抗議，甚至導致棄養。所以我希望透過 System Prompt，讓 AI 更像一個「真正在跟你聊天的專業顧問」，而不是只會背資料的機器人。

#### 1.2 我怎麼設計 System Prompt
我寫了一套完整的指令，內容如下：

---

你是一位專業、親切且負責任的「寵物照護專家 AI」，使用繁體中文回答。

你的任務是協助使用者處理寵物的飼養、飲食、行為與健康問題。

【回答原則】
- 先理解情況，再給建議，不要直接下結論。
- 資訊不足時，主動詢問關鍵資訊。
- 用簡單、實用、條列式的方式回答。
- 不確定的事情要明確說明，不要編造資訊。
- 健康問題不可直接診斷；遇到嚴重或緊急症狀，應建議盡快就醫。
- 不建議使用人類藥物或沒有可靠依據的偏方。

【飼養／選擇寵物】
當使用者詢問「適合養什麼」、「推薦哪種狗／貓」或「我適不適合養寵物」時，不要直接推薦品種。

先了解：
1. 居住環境：公寓、透天、空間大小、是否允許養寵物
2. 工作型態：學生、上班族、輪班、遠端工作等
3. 每天不在家的時間與可陪伴寵物的時間
4. 每月可負擔的預算與突發醫療費能力
5. 家庭成員、室友、其他寵物及過敏情況
6. 過去是否有飼養經驗
7. 想養寵物的原因與期待
8. 未來是否可能搬家、出國或改變生活型態

再根據「生活環境 × 陪伴時間 × 預算 × 工作型態 × 飼養經驗」分析適合的寵物類型，並說明適合與可能遇到的困難。

【健康與行為】
遇到寵物症狀時：
- 說明可能原因，但不要把可能性說成確定診斷。
- 告訴使用者可以先觀察或做什麼。
- 清楚指出哪些情況需要獸醫。
- 行為問題應考慮生理、心理、環境等因素，不要直接認定寵物是在報復或故意搗蛋。
- 優先提供安全、正向的訓練與環境改善方式。

【回答風格】
先給簡短結論，再提供：
「可能原因 → 建議做法 → 注意事項／何時就醫」

你的目標不是替使用者做決定，而是根據使用者的實際生活條件，提供安全、個人化且可執行的建議。

---

#### 1.3 前後對比測試結果

**對照組（未下 System Prompt）：**
*   **提問：** 「我想要飼養鸚鵡，有什麼推薦的品種嗎？」
*   **結果：** AI 直接推薦「玄鳳鸚鵡」，並條列其體型、壽命與優缺點。
*   **分析：** 回覆非常單向，缺乏互動，也沒有考慮現實條件，就像在查百科全書。

**實驗組（下 System Prompt 後）：**
*   **提問：** （同上）
*   **結果（第一階段 - 需求採集）：** AI 沒有直接推薦，而是先熱情地回應，並反問我「居住環境、陪伴時間、噪音接受度、飼養經驗、預算」等五大需求指標。

### 第二部分：Tool Calling 導入與實測

為了解決 AI 無法回答「即時性」與「地理位置」相關問題的痛點，我開放了 **Web Search（網路搜尋）** 工具給 Agent。

**實測提問：** 「我住在桃園中壢，如果需要看醫生，有推薦的動物醫院嗎？」

**Agent 內部運作（Tool Calling 過程）：**
AI 判斷此問題需要即時資訊，自動觸發了三次搜尋指令：
1. `搜尋：桃園 中壢 鸚鵡 特殊寵物 獸醫院 推薦`
2. `搜尋：中壢 特殊寵物 醫院 鳥 OR 桃園 鳥類 動物醫院`
3. `搜尋：桃園 鸚鵡 獸醫 OR 特寵 醫院 推薦`

**最終輸出結果：**
AI 成功統整網路資訊，提供以下建議：
*   中壢/平鎮首選：原野特殊寵物專科醫院（附地址、電話、預約提醒）。
*   桃園區推薦：逗號動物醫院、普羅動物醫院。
*   北部頂級備案：台北凡賽爾賽鴿寵物鳥醫院。
*   額外建議：提醒帶鳥寶就醫的注意事項（透氣外出籠、保暖、基本健檢）。

**觀察與分析：**
這次 Tool Calling 的實測過程中，AI 完全沒有發生錯誤，也準確判斷出「需要上網搜尋」的時機。它不僅成功找到中壢當地的特寵醫院，還自動整理了地址、電話與預約提醒，甚至補充了就醫注意事項。這表示 AI 已經能將網路上的碎片資訊，轉化成對使用者真正有用的在地化建議。

## 📱 Phase 1-2 測試結果
目前已完成：
*   System Prompt 設計與前後對比驗證。
*   Web Search Tool Calling 導入。
*   鸚鵡飼養顧問人格建立（能主動提問、根據條件篩選、給出完整建議）。
*   在地化資訊查詢功能（特寵醫院推薦）。

## 💡 今日心得
這次最大的收穫是體會到 System Prompt 的威力。它讓 AI 從一個「無情的資料庫」，變成一個「會跟你聊天、關心你狀況的專業顧問」。而 Tool Calling 則讓 AI 不再只會講古，而是能真正查出「現在、這裡」的資訊。

從今天的實測可以看出，Agent 已經能主動發起搜尋，並把網路上零散的資訊整理成有用的建議。這讓我對 AI Agent 在寵物諮詢這類垂直領域的應用潛力更有信心。

## 🚀 下一步
目前 AI 已具備推薦與查詢能力，但缺乏長期記憶。接下來（Phase 1-3）預計加入「記憶（Memory）」功能，讓 AI 能記住使用者的飼養背景，提供更個人化的建議，朝向 AI Digital Twin 的目標邁進。
